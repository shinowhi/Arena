## Cross-lens TOP fixes (ordered by impact)

1. **Commit to Vietnamese K12.** `<html lang="en">` → `vi` (`app/layout.tsx:22`);
   ~40 pages still English (tutor greeting, groups/market pause, ghost leak
   `app/ghosts/page.tsx:104`, `prime` jargon `app/transparency/page.tsx:48`,
   machine ids `app/graph/GraphView.tsx:114`); `translate="no"` on BossLearn;
   replace `window.confirm` (`app/thpt/page.tsx:232`) with a branded dialog.
2. **Break the PageHeader template.** `components/ui/PageHeader.tsx:17` stamps
   kicker + single-accent title + middle-dot sub on ~40 pages. Give each page a
   characteristic-first hero; add `text-wrap-balance` to the shared h1.
3. **Demote ALL-CAPS eyebrows** to sentence case or delete (~35 pages, e.g.
   `app/pvp/page.tsx:78`, `app/groups/page.tsx:9`). Max one display eyebrow/page.
4. **Replace middle-dot meta strings** with structured rows/chips (~40 pages,
   e.g. `app/thpt/page.tsx:403`, `app/royale/[id]/page.tsx:124`).
5. **One SVG icon set; purge emoji/text glyphs.** 💡 drill/misses/paper/pvp,
   ✓/✗ drill/essay/hsa/paper/review, ⚡ arena, 🏆 boss, 🎁 friends, 🎉
   parent/roadmap, ⚔ roadmap, ❓ thpt, ★ vip, ▶/❚❚ progress, ↑→↓ mastery.
6. **Fix the error pattern app-wide.** Raw `{error}`/fragments with no fix step
   (~15 pages: adaptive, badges, cards, countdown, diary, family, gauntlet,
   progress, revenge, royale…); add `role=alert`/`role=status` (scan :563,
   streak :40, roadmap :137, plan :51, vip bar); never swallow
   (`app/vact/page.tsx:145`, also adaptive/misses/paper/hsa/thpt grade paths);
   bare `…` busy labels → verb + status (duel, duel/[id], friends).
7. **Perf: exam pages.** Unmemoized `katex.renderToString` + 1s tickers (thpt
   50Q, vact, hsa, paper, boss); per-keystroke full-paper sessionStorage writes
   (thpt/vact/hsa/paper); add error boundaries app-wide; next/image for static
   art; dynamic-import mode-gated modals (AvatarBuilder, ScreenCapture,
   DiagnosisReveal, ShareCard); fix server waterfalls (admin, admin/billing, vip).
8. **Accent contract.** Amber CTAs (groups, market, parent), emerald (me),
   sky→emerald gradients (mastery), per-card red washes (arena) vs red/cyan
   brand + arena-btn tokens. Groups and market are verbatim duplicate pause
   pages — differentiate or merge.
9. **Headings p→h2** on admin, billing, cards, center, diary, duel, exam, pvp,
   revenge, royale, plan, ghosts.
10. **Interaction a11y.** Arrow-key support for role=tab/radio (scan, friends,
    exam/review, vact, duel, royale, hsa); touch targets ≥44px (py-1/py-2
    pills, h-6 checks, text-xs toggles); missing hover/focus-visible (~11
    spots); purge `transition-all` (arena, boss, countdown, ghosts, scan);
    reduced-motion guards (progress 800ms interval, smooth scroll chat/tutor,
    graph lifts); fail-soft-to-empty masks fetch errors (arena, billing, tutor).

## Per-page findings — other lenses (systemic only)

from reviewer notes (all bodies were opened).

pages); silent grade catches (adaptive, misses, paper-ok, hsa, vact, thpt);
role=tab/radio without arrow keys (scan, friends, exam/review, vact, duel,
royale, hsa); plain-p status/errors without live regions (arena, friends,
parent, roadmap, plan, diary, countdown, cards, streak, ghosts-poll);
sub-44px controls (pills, h-6 checks, text-xs toggles). Contrast from Tailwind
hex, not measured pixels.

radio/tab ARIA without arrow keys (duel, royale, vact, hsa, scan,
exam/review, friends); fail-soft-to-empty (arena bosses/leaderboard, billing
orders, tutor threads); raw-color buttons vs arena-btn tokens (chat, friends,
login, vip, center, parent, roadmap, billing, admin); taste tells (emoji,
kickers, gradient titles, hover lifts, hero + 3-card grids).

**perf:** KaTeX re-render + 1s tickers (thpt 50Q, vact, hsa, paper, boss);
per-keystroke sessionStorage (thpt/vact/hsa/paper); server waterfalls (admin,
admin/billing, vip); no next/image; no error boundaries; static modal imports
(AvatarBuilder, ScreenCapture, DiagnosisReveal, ShareCard). 35 client vs 16
server pages.
